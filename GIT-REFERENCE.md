# Git reference — what lives on GitHub, not in this workspace

Repository: github.com/euromilesofficial/Arena-Agent--WACRM (branch `main`). Full history lives there. The workspace keeps no `.git`.
Head when this manifest was written: `6901f5d`. Every path below was checked against the Git blob before its local copy was removed.

## Restore a file

```
bash scripts/git-fetch.sh <path>          # e.g. WACRM-CMS.html or src/lib/theme-font-data.ts
bash scripts/git-fetch.sh --list          # everything in Git that is not in the workspace
```

## Save work

```
bash scripts/git-sync.sh "what changed"   # copies working files to a temp clone, commits, pushes, verifies the remote
```
