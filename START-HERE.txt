WACRM Website CMS — start here
==============================

TL;DR
  Double-click  WACRM-CMS.html.  That is the whole app: one self-contained file,
  no install, no build, no server, no internet. 4.75 MB.

How to run it — pick one
------------------------
  1. Just look at it (recommended)
       WACRM-CMS.html                 ← double-click

  2. Serve it locally (some browsers prefer http:// to file://)
       python3 serve.py               → http://localhost:4173
       (zero packages; Python 3 only)

  3. Work on the source
       npm ci                         ← exact versions, ~5 s
       npm run build                  → rebuilds WACRM-CMS.html + the zip
       open WACRM-CMS.html
     NOTE: `npm run dev` (Vite, :5173) currently fails with a React hooks-order
     error that only the dev build enforces. The built file is the verified
     path; see README §19.

What is built
-------------
  Overview            sidebar → Overview            #/overview        M1
  Sites & Domains     sidebar → Sites & Domains     #/sites           M2
  Pages & Routes      sidebar → Pages               #/pages           M3
  Visual Builder      sidebar → Visual Builder      #/builder         M4
    + AI              build a page from a prompt, or rewrite copy in-canvas
  Block Library       sidebar → Block Library       #/library         M5
  Theme Studio        sidebar → Theme Studio        #/theme           M6 / M6.1

  Everything else in the sidebar (Layouts & Templates, Menus, Media, Forms,
  Publishing, SEO, Localization, Security, Settings) renders a placeholder that
  states what the module will contain. Publishing belongs to Module 11 alone —
  nothing in this build publishes.

States — reachable, not decorative
----------------------------------
  Beaker icon, top right → Default / Loading skeletons / Empty (no data in
  range) / Error — service down / Publish conflict / Permission denied (Viewer).

  Save paths are compare-and-swap: a stale save returns 409 and opens the
  conflict modal. Theme Studio saves a DRAFT only.

Which file is which
-------------------
  WACRM-CMS.html    the built, runnable app   ← the one you open
  index.html        Vite's dev entry; opened from disk it explains itself and
                    forwards to WACRM-CMS.html
  src/              React 19 + TypeScript source
  scripts/          handover · package · qa-all · fetch-theme-fonts · ensure-font-data
  serve.py          zero-dependency static server (Python 3)
  qa/               WebP captures of the audited states (never shipped)
  checkpoint.sh     build → commit → push → verify the remote head

If the page is ever blank
-------------------------
  - Make sure you opened WACRM-CMS.html (or index.html), not src/main.tsx.
  - Some browsers quarantine scripts in files that arrived inside a ZIP on
    macOS. Either allow it, or use option 2: python3 serve.py.
  - Nothing is fetched from the network, so a blank page is never a CDN problem.
