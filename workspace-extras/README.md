# WACRM — Website CMS

| Folder | What it is |
| --- | --- |
| `wacrm-app/` | **The deliverable.** React 19 + TypeScript + Vite project — Overview dashboard (module 1), all states, all flows. See `wacrm-app/README.md`. |
| `wacrm-app/preview.html` | Single-file production build — open in any browser, offline, no server. |
| `wacrm-app.zip` | Source archive (no `node_modules`) — `npm install && npm run dev`. |
| `wacrm/` | The earlier vanilla HTML/CSS/JS prototype, kept only as a design/motion reference. |
| `uploads/` | Reference material supplied for the build. |

Next modules (Sites & Domains, Pages, Visual Builder, …) get added to the same
React project, one at a time.
